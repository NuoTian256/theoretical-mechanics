# 教师资格证资料

本文件夹用于整理**教师资格证（教资）**备考资料，与仓库里的理论力学资料并列存放。

## 暂定分类（可按需调整）
- **综合素质**
- **教育知识与能力**
- **学科知识与教学能力**（按报考学科细分，如中学物理 / 中学数学 / 中学语文等）

## 使用方式
- 把对应资料放进上面的子文件夹即可；若暂时不分子类，直接放本目录下也行。
- 文件名建议带清楚「主题 + 年份/版本」，方便检索，例如：`教育知识与能力_简答题汇总_2026.md`。
- 新增或更新资料后：`git add .` → `git commit -m "说明"` → `git push`。
